# Dotfiles

Personal dotfiles, NixOS configuration, install scripts, and other utilities.

## Quick Reference

All NixOS commands are run from the `nixos/flake/` directory:

```sh
cd nixos/flake
```

### Apply System & Home Manager Configuration

Home Manager is integrated into the NixOS flake, so both system and user
configuration are applied together in a single command:

```sh
sudo nixos-rebuild switch --flake .#<machine>
```

For example:

```sh
sudo nixos-rebuild switch --flake .#vivobook-x509fb
```

### Test Build (without applying)

```sh
nix build .#nixosConfigurations.<machine>.config.system.build.toplevel
```

### Update Flake Inputs

Pull the latest versions of nixpkgs and home-manager:

```sh
nix flake update
```

Then rebuild and switch (see above).

### Modifying Packages

- **System packages** — edit `nixos/sys/packages.nix`
  (`environment.systemPackages`)
- **User packages & programs** — edit `nixos/home/home.nix`
  (`home.packages` and `programs.*`)

### List Available Machines

```sh
nix eval --json --apply builtins.attrNames .#nixosConfigurations | jq -r '.[]'
```

## Overview

This repo manages system configuration across multiple machines using
[NixOS](https://nixos.org/) with [Nix Flakes](https://wiki.nixos.org/wiki/Flakes)
and [Home Manager](https://github.com/nix-community/home-manager).

### Project Structure

```txt
├── nixos/
│   ├── flake/
│   │   ├── flake.nix          - Main Nix entry point (inputs & machine definitions)
│   │   └── flake.lock         - Pinned dependency versions
│   ├── home/
│   │   └── home.nix           - Home Manager user configuration (packages, git, etc.)
│   ├── machines/               - Per-machine hardware & system config
│   │   ├── vivobook-x509fb/
│   │   ├── acer-vx15-nixos/
│   │   └── zlx-nixos-desktop/
│   └── sys/                    - Shared NixOS system modules
│       ├── boot.nix
│       ├── gnome_desktop_env.nix
│       ├── i18n.nix
│       ├── networking.nix
│       ├── packages.nix
│       ├── users.nix
│       ├── extra_services.nix
│       └── ledger-nano-udev-rules.nix
├── .config/                    - XDG config files (e.g. fish shell)
├── install/                    - Install/bootstrap scripts
├── utils/                      - Utility scripts
├── .bash_aliases               - Bash aliases
├── .gitconfig                  - Git configuration
├── .vimrc                      - Vim configuration
└── .editorconfig               - Editor settings
```

### Shared System Modules

| Module                       | Purpose                                |
| ---------------------------- | -------------------------------------- |
| `sys/boot.nix`               | Bootloader and console settings        |
| `sys/gnome_desktop_env.nix`  | GNOME desktop with GDM display manager |
| `sys/i18n.nix`               | Locale and timezone                    |
| `sys/networking.nix`         | NetworkManager and DNS                 |
| `sys/packages.nix`           | System packages, fonts, Nix settings   |
| `sys/users.nix`              | User accounts and groups               |
| `sys/extra_services.nix`     | Printing and other services            |
| `sys/ledger-nano-udev-rules.nix` | udev rules for Ledger hardware wallets |

## Getting Started

### Prerequisites

- A running [NixOS](https://nixos.org/download.html) installation
- **Nix ≥ 2.18** (required by nixpkgs 25.11). Check with `nix --version`.
  If upgrading from an older NixOS (e.g. 21.11), upgrade Nix first:

  ```sh
  sudo nix-channel --add https://nixos.org/channels/nixos-25.11 nixos
  sudo nix-channel --update
  sudo nix-env -iA nixos.nix
  sudo systemctl restart nix-daemon
  ```

- Nix with flakes enabled (add `experimental-features = nix-command flakes`
  to `/etc/nix/nix.conf` or use the flake's built-in config)

### Clone the Repo

```sh
git clone git@github.com:Aleione/dotfiles.git
cd dotfiles
```

## Adding a New Machine

1. Create a new directory under `nixos/machines/<hostname>/`
2. Add a `hardware-configuration.nix` (generated by `nixos-generate-config`)
3. Add a `configuration.nix` that imports the shared modules from `nixos/sys/`
   and the hardware config:

   ```nix
   { config, pkgs, ... }:
   {
     imports = [
       ./hardware-configuration.nix
       ../../sys/boot.nix
       ../../sys/networking.nix
       ../../sys/i18n.nix
       ../../sys/users.nix
       ../../sys/gnome_desktop_env.nix
       ../../sys/extra_services.nix
       ../../sys/packages.nix
     ];

     system.stateVersion = "25.11"; # Set to your install version
   }
   ```

4. Register the machine in `nixos/flake/flake.nix` under `nixosConfigurations`
